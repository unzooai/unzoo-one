# Unzoo One C1 / Flow One 品牌识别系统

> 版本：C1 System v1
> 状态：品牌设计工作稿
> 核心原则：先让符号在黑白中成立，再让它在数字环境中拥有生命。

## 1. 品牌核心

### 1.1 品牌定位

Unzoo One 是用户的个人智能工作中枢。它让一个意图可以安全地调动 Brain、终端、浏览器、文件、连接器和自动化，并把控制权、证据与结果留给用户。

### 1.2 品牌承诺

> **One intent. Every capability.**

中文表达：

> **一个意图，调动所有能力。**

它不是“无所不能”的承诺，而是对统一入口、统一权限和统一结果的承诺。

### 1.3 品牌性格

- Calm：不制造虚假的忙碌与紧迫感。
- Capable：用真实结果证明能力。
- Open：允许不同 Brain 与 Provider 进入和退出。
- Sovereign：用户拥有授权、数据和停止权。
- Precise：状态、风险和结果都有明确表达。

## 2. C1 标志概念

`Flow One` 由一条连续路径完成：

1. 左端是开放入口。
2. 路径向下形成 `U`，代表 Unzoo 与开放能力边界。
3. 底部连续曲线代表不同能力在同一任务中汇合。
4. 右臂上升成为数字 `1`。
5. 数字 1 的斜肩指向内部，不是向外攻击的箭头。

标志没有眼睛、机器人、轨道和封闭圆环。它不假装人格，也不暗示监视用户。

## 3. 几何构造

### 3.1 标准画板

- ViewBox：`256 × 256`。
- 标准描边：`26`。
- 端点：Round。
- 转角：Round。
- 视觉中心：`x = 128`。
- 左端基准：`(60, 58)`。
- One 顶点：`(196, 52)`。
- 斜肩终点：`(158, 88)`。
- 最低视觉位置：约 `y = 214`。

左端比 One 顶点低 6 个单位，形成轻微向右上方的行动趋势。不得把两端机械拉平。

### 3.2 单路径约束

标准主标必须保持一条连续路径：

```svg
M60 58v74c0 50 27 82 68 82s68-32 68-82V52l-38 36
```

不允许：

- 把 U 和 1 拆成两个颜色。
- 在路径中心加入眼睛或圆点。
- 额外增加外框。
- 把斜肩改成箭头。
- 把底部压扁成标准字体 U。

### 3.3 安全空间

安全空间单位 `x` 等于标准描边宽度。

- 独立主标四周：至少 `2x`。
- 横向 Lockup 四周：至少 `1.5x`。
- App Icon 内部：图形到安全边界至少 `1.25x`。
- 与合作品牌并列：至少 `3x`。

### 3.4 最小尺寸

| 场景 | 最小尺寸 | 资产 |
| --- | --- | --- |
| Favicon | 16px | `unzoo-one-favicon.svg` |
| 系统托盘 | 16px | Optical 版 |
| 紧凑导航 | 20px | Optical 版 |
| 常规导航 | 24px | Optical 或标准版 |
| 独立主标 | 32px | 标准版 |
| 横向 Lockup | 120px 宽 | 横向版 |
| 印刷 | 8mm 高 | 黑色单色版 |

16–24px 版本加粗描边并放大斜肩，不能直接缩小标准版代替。

## 5. Wordmark

### 5.1 写法

品牌名始终写作：

```text
Unzoo One
```

视觉字标使用小写：

```text
unzoo one
```

正文首次出现使用 `Unzoo One`，后续可以使用 `One`。不使用：

- UNZOO ONE，除非是极小标签。
- UnZoo、UnzooOne、unzoo-one。
- “Unzoo 1”。
- 中文音译品牌名。

### 5.2 字标关系

- `unzoo` 与 `one` 使用相同字重。
- 两词之间保持正常词间空格，不使用分隔点和竖线。
- 字标高度约为图形高度的 `0.38–0.44`。
- 图形与字标间距约为 `0.75x`。

当前 Lockup 使用字体引用作为设计工作稿。正式发布前需要完成字标微调与轮廓化：

- 定制字母 `u` 的开口比例，使其呼应主标。
- 收紧 `nz` 与 `on` 字偶距。
- 调整两个 `o`，避免机械重复。
- 确认 Inter 或最终字体许可。

## 6. 色彩

### 6.1 核心色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| Obsidian | `#080A0F` | 深色品牌背景 |
| Ink | `#111318` | 浅色背景主标和文字 |
| Porcelain | `#F7F8FA` | 深色主文字与浅色画布 |
| Signal Indigo | `#6B70F6` | 默认产品主标与关键焦点 |

### 6.2 数字 Signal

| 名称 | 色值 | 含义 |
| --- | --- | --- |
| Aqua | `#5FE1FF` | 感知、输入 |
| Cobalt | `#657FF7` | 协调、运行 |
| Iris | `#926BFA` | 推理、生成 |

Signal Gradient：

```css
linear-gradient(135deg, #5FE1FF 0%, #657FF7 52%, #926BFA 100%)
```

渐变只用于：

- 数字产品中的主标。
- App Icon。
- 智能正在运行的短暂状态。
- 小面积品牌入口。

渐变不能用于审批、错误、成功或大段文字。

### 6.3 使用比例

典型深色页面：

- 82% Obsidian 与深色表面。
- 14% Porcelain、Silver 与结构线。
- 不超过 4% Signal。

品牌高级感来自低颜色占比，不来自增加渐变面积。

### 6.4 可访问性

- Signal Indigo 不作为深色背景上的正文色。
- 正文对比度满足 WCAG AA。
- 状态不能只通过 Signal 色区分。
- 黑白打印时所有核心信息仍然成立。

## 7. 字体

### 7.1 产品字体

```css
font-family: Inter, "SF Pro Display", "Segoe UI", "Noto Sans SC", sans-serif;
```

### 7.2 角色

| 角色 | 建议字重 | 用途 |
| --- | --- | --- |
| Display | 500–540 | 品牌主张 |
| Heading | 540–600 | 页面与模块标题 |
| Body | 400–450 | 正文与产品说明 |
| Label | 550–650 | 状态、按钮、导航 |
| Mono | 450–500 | 命令、ID、时间与证据 |

### 7.3 排版性格

- 左对齐优先。
- 大标题使用紧字距，正文保持自然字距。
- 中文不使用夸张拉宽字距。
- 不用全大写英文制造“科技感”，仅短标签例外。
- 单屏只保留一个强视觉标题。

## 8. 辅助图形

### 8.1 Flow Line

Flow Line 从主标的单路径逻辑延伸，用于：

- 连接任务步骤。
- 解释能力编排。
- 品牌页面中的视觉引导。
- 动效轨迹。

它必须是一条连续、可追踪的线，不能变成随机粒子和装饰波纹。

### 8.2 Flow Field

[`flow-field.svg`](../brand/c1/patterns/flow-field.svg) 使用大尺度裁切的 C1 路径形成背景。

规则：

- 单屏最多三条路径。
- 透明度 `8%–16%`。
- 不放在正文后方。
- 不与主标同时争夺视觉中心。

### 8.3 One Point

产品内可以用一个 4–8px 实心点表示当前唯一焦点，但它不是主标的一部分：

- Aqua：正在感知。
- Cobalt：正在运行。
- Attention：等待用户。
- Success：已验证完成。

## 9. 动态标识

### 9.1 标准进入动效

[`unzoo-one-mark-motion.svg`](../brand/c1/motion/unzoo-one-mark-motion.svg) 沿路径从左端绘制：

1. 进入开放边界。
2. 沿底部汇合。
3. 上升成为 One。

总时长 `900–1200ms`，只播放一次。

### 9.2 产品状态

标志不旋转、不持续呼吸。产品状态通过局部路径表现：

| 状态 | 动态 |
| --- | --- |
| Idle | 静止 |
| Listening | 左端出现一次 180ms 亮度提升 |
| Thinking | Signal 沿路径单向移动 |
| Acting | 亮度集中到右侧 One |
| Waiting approval | 停止运动，使用 Attention 点 |
| Complete | 路径恢复纯色，出现 Success 点 |
| Error | 不闪烁，显示 Danger 状态与文字原因 |

遵循 `prefers-reduced-motion`；减少动效时直接显示完整标志。

## 10. App Icon

### 10.1 结构

- Obsidian Superellipse 底板。
- 内部 C1 使用 Signal Gradient。
- 极轻量径向 Halo 只存在于数字图标。
- 1px 内部高光帮助 Windows 深色任务栏分离边界。

### 10.2 平台适配

- Windows：导出 16、20、24、32、48、64、128、256px。
- macOS：遵循平台安全区，不把圆角画满模板边缘。
- Browser Favicon：使用独立 Optical 标，不缩放 App Icon。
- 系统通知：优先单色主标，减少复杂底板。

## 11. 摄影与视觉内容

Unzoo One 不使用机器人、发光大脑和仿生眼睛。

推荐视觉语言：

- 用户真实工作环境的局部细节。
- 文档、终端、浏览器与现实结果之间的联系。
- 安静、低饱和、有清晰光源。
- 能表达“一个意图连接多个行动”的构图。

避免：

- 霓虹赛博朋克城市。
- 无意义粒子流。
- 拟人机器人助手。
- 夸张全息屏幕。
- 大面积紫蓝渐变背景。

## 12. 产品中的品牌

### 12.1 品牌出现位置

- 应用启动。
- 左上角产品入口。
- 空状态。
- About 与设置。
- Artifact 封面，可选。

执行任务时，品牌不应占据中心；中心应留给任务、证据和结果。

### 12.2 Provider 关系

Unterm、Unzoo Browser、Codex、Claude 和 Connector 都是 Provider 或 Brain，不与 One 主标平级争夺页面视觉。

- One 主标表示统一任务与控制层。
- Provider 使用中性 Badge。
- Provider 品牌色只保留在图标小面积。
- 一个页面不展示多个大型品牌标志。

## 13. 与 Unzoo Browser 的家族关系

C1 首先属于 Unzoo One。Browser 不直接复用数字 1 的斜肩。

未来家族规则：

- 共享“单一连续路径”原则。
- 共享开放边界语义。
- 不强制共享同一颜色。
- One 的右臂是 `1`。
- Browser 的右臂可以转化为页面视界或导航切口。
- 母品牌 Unzoo 使用不含产品内部语义的开放路径。

在 One 完成商标清查前，不应反向修改 Browser 正式标志。

## 14. 品牌语言

### 14.1 语气

- 用具体动作，不用人格化承诺。
- 用证据说明能力。
- 明确区分完成、等待和失败。
- 不把权限要求包装成便利。

### 14.2 推荐表达

| 场景 | 表达 |
| --- | --- |
| 品牌主张 | One intent. Every capability. |
| 产品说明 | 从一个目标开始，调动需要的工具，并保留完整证据。 |
| 运行中 | 正在比较 12 个来源 |
| 等待审批 | 发送给 1 位联系人前需要你的确认 |
| 完成 | 报告已生成；外部发送尚未执行 |
| 故障 | 浏览器登录已过期，可从第 3 步继续 |

## 15. 禁止用法

- 不拉伸、压缩或旋转。
- 不改变单路径结构。
- 不添加眼睛、圆点、轨道、盾牌和外框。
- 不使用彩虹渐变。
- 不把标志填满整张背景。
- 不在复杂照片上直接使用 Signal 版。
- 不给静态主标增加投影和外发光。
- 不把斜肩单独当作箭头图标。
- 不在普通正文中把 `one` 着色强调。
